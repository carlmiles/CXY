# 杭州倍力钣金产品清单 — 判断"产品匹配"评分时查阅

判断一家候选企业时，逐条对照其产品照片/说明书/BOM 是否出现以下任一类别。命中类别越多、越核心，"产品匹配"30 分应打得越高。每个类别列出中文叫法和对应英文关键词，英文关键词用于组合搜索（行业词 + 产品词 + 采购行为词）。

## 1. 盖板 / 罩类

中文：上盖、顶盖、箱盖、盒盖、遮盖板、防护罩、设备罩、金属保护罩

英文：Cover / Top Cover / Metal Cover / Sheet Metal Cover / Enclosure Cover / Protective Cover / Equipment Cover

## 2. 支架 / 支撑 / 托架类

中文：支架、支撑件、托架组件、托盘、挂架、固定支架、设备支架

英文：Bracket / Mounting Bracket / Support Bracket / Metal Bracket / Sheet Metal Bracket / Mount / Tray / Support / Holder

## 3. 安装板类

中文：控制板安装板、端子安装板、风扇安装板、电源安装板、PCB 安装板、模块安装板、各类设备安装板

英文：Mounting Plate / Mounting Panel / Control Mounting Plate / Terminal Mounting Plate / Fan Mounting Plate / Equipment Mounting Plate / Backplate

## 4. 底板 / 底框 / 底座类

中文：底框、底壳、底板、底座、设备基础框架

英文：Base Plate / Base Frame / Bottom Plate / Bottom Cover / Metal Base / Equipment Base / Chassis Base

## 5. 壁挂 / 挂墙类

中文：壁挂板、锁墙壁挂板、壁挂连接板、背挂支架、墙面安装支架

英文：Wall Mount / Wall Mounting Plate / Wall Bracket / Wall Mount Bracket / Back Mounting Bracket / Wall Plate

## 6. 机箱 / 箱体 / 壳体类

中文：盒体、机架、机箱、箱体、机笼、设备外壳、电气壳体

英文：Enclosure / Metal Enclosure / Sheet Metal Enclosure / Chassis / Metal Chassis / Cabinet / Housing / Metal Housing / Rack / Cage / Equipment Enclosure / Electrical Enclosure

## 7. 分隔板 / 连接板 / 侧背板类

中文：分隔板、中隔板、后背板、转接板、连接板、侧板、背板

英文：Divider / Partition Plate / Back Plate / Rear Panel / Side Panel / Adapter Plate / Connection Plate / Internal Panel

## 8. 面板类

中文：配电前面板、配电后面板、控制面板、操作面板、设备前面板、各类定制金属面板

英文：Front Panel / Rear Panel / Control Panel / Metal Panel / Distribution Panel / Equipment Panel / Sheet Metal Panel

## 9. 挡板类

中文：挡板、铜排挡板、急停挡板、安全挡板、防护挡板

英文：Baffle / Shield / Guard Plate / Safety Guard / Protective Plate / Busbar Shield / Emergency Stop Guard

## 10. 导轨类

中文：导轨、模块微断导轨、钢导轨、嵌入式空开导轨、设备安装导轨、电气安装导轨

英文：DIN Rail / Mounting Rail / Steel Rail / Equipment Rail / Electrical Mounting Rail

## 使用方式

不要只搜产品词本身（那样会大量命中钣金同行/贸易公司）。把这些词和行业词、采购行为词组合，例如：

- `sheet metal enclosure` + `power supply manufacturer` + 国家名
- `mounting bracket` + `industrial automation` + 国家名
- `metal chassis` + `EV charger manufacturer` + 国家名

命中越多类别、且这些零件明显是设备的结构性组成部分（不是偶尔用到的小配件），产品匹配分越高。
