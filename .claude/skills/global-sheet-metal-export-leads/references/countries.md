# 国家优先级与本地语言检索指南

## 使用原则

结果必须按国家组织。**不能因为存在下面的国家列表就机械按顺序搜索** —— 应优先搜索当前更容易产生实际订单的市场，再逐步扩展到其他国家。

每进入一个国家，都要在英文关键词组合之外，再加一轮该国当地语言关键词搜索。原因：很多当地中小企业的官网、招聘信息、采购公告只用本地语言撰写，纯英文搜索完全找不到它们，而这些正是规模适中、供应链尚未固化、最容易进入的目标客户。

例如：
- 德国 → 使用德语关键词重新搜一遍
- 法国 → 使用法语
- 意大利 → 使用意大利语
- 西班牙 → 使用西班牙语
- 荷兰 → 使用荷兰语
- 日本 → 使用日语
- 韩国 → 使用韩语

本地语言关键词的构造方式和英文一样：把当地语言的"行业词"+"产品词"+"采购/供应商"类词组合，而不是逐字直译英文搜索模板。

## 默认排除

- 中国大陆钣金工厂（同行，不是客户）
- 单纯贸易公司
- Alibaba / Made-in-China 上的店铺
- 没有独立官网的低可信企业
- 完全没有实体产品的公司
- 明显已经停止运营、信息严重过期的企业
- 与钣金产品不存在明显关系的企业
- 年营收明显超过 USD 300M 且没有明显采购机会的大型企业
- 员工数量明显超过目标范围、且供应商体系非常成熟的企业

可以保留真正拥有海外销售网络、品牌和稳定终端客户的专业经销商（见 SKILL.md 的"经销商路线"）。
